Theory:
Any modern control systems must operate accurately smoothly, and efficiently. Likely we are in the era
of  modern  technologies  where  we  all  are  busy  in  building  something  and  so  everybody  has  high
expectations  on  our  buildings.  And  more likely  we love  to  control  and  automate  them.  So  we  have
control system that has two types open loop control system and closed loop control system.  Nearly
everything  with  us  are  open  loop  control  system  as  we  does  control  them  with  our  hands  or  put  a
reference value and the controller reach that value manipulating the system. But mostly we are lazy to
work for and so we does it automatically like electric vehicles(AVR), robotics, conveyors, and every
automatic things. And this automatic things are made in closed loop control system which is exactly
same as open loop control system but with a extra module feedback control. [1]

Fig 2.1: PID Controller [4]

A  controller  compares  the  desired  references  with  the  actual  output  of  the  system  and  generates  a
correction signal. The most widely used controller in Engineering is PID, PI and PD controllers. Each
of  this  provides  different  performance  characteristics  in  terms  of  stability,  speed  of  response,  and
steady-state accuracy. [2] In PID P means proportional, I means integration and D means derivatives.
Every value of PID is really important for a system and P decides system response or timing of a system
if  P  increases  system  response  faster,  risetime  decreases,  overshoot  and  oscillation  increases.  For
increasing the value of I error of steady-state reduces, output aligns with the reference value more, but
oscillation increases, settling time also increases so does system becomes unstable. And if we increase
the value of D overshoot decreases, oscillation decreases also the system becomes more smooth but on
the other hand the system becomes noise sensitive, responses become slow. In short Kp for speed, Ki
for accuracy and Kd for stability. [1] PI and PD are two sub types of PID where PI means the value of
D is zero and for PD value of I is zero.

Discussion:
The open-loop motor shows slow and inaccurate response. The PI controller eliminates steady-state
error but increases rise time. The PD controller improves speed but still has steady-state error. The PID
controller provides the best response: fast rise time, minimal overshoot, and zero steady-state error. In
every case if we see PI it has only two parameters proportional and integration for which it’s system
response is well enough  as well as rise time means it’s accurate but  high overshoot which says the
system is not stable. If we look at PD it rise time is really low as well as peak time with no settling time
which describes the PD controller is efficient and stable but it not that accurate. But among them we
can say PID controller is best because it includes all means the system is stable reliable accurate with
low rise time and settling time and best among this are it overshoot is 0.1725% which is really low.
Conclusion:
The simulation results clearly showed that each controller has distinct characteristics. The PI controller
eliminated steady-state error but introduced large overshoot and slower settling, making it less suitable
for  high-performance  applications.  The  PD  controller  provided  very  fast  response  and  improved
stability  but  failed  to  remove  steady-state  error.  The  PID  controller,  which  combines  proportional,
integral, and derivative actions, delivered the best overall performance by achieving fast rise time, very
low  overshoot,  zero  steady-state  error,  and  stable  settling  behaviour.  Both  MATLAB  and  Simulink
results verified that PID control is the most effective strategy electric vehicles, robotics, and industrial
automation, where accuracy, stability, and fast response are all critical.
