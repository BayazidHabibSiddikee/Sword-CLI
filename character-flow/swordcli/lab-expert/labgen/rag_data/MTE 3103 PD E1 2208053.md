Introduction:
The  ATmega8  is  a  widely  used  8-bit  microcontroller  from  the  AVR  family,  originally
developed by Atmel. It is designed for embedded systems and offers a balanced combination
of performance, low power consumption, and ease of use. With features such as 8 KB of flash
memory, built-in analog-to-digital converters, timers, and communication interfaces like SPI
and  USART,  the  ATmega8  is  suitable  for  a  variety  of  applications  including  robotics,
automation, and sensor-based systems.  Its compact  design  and reliability make it  a popular
choice for both beginners and professionals in microcontroller-based projects.
To program the ATmega8, an Arduino Uno can be used as an In-System Programmer (ISP).
This  method allows the  microcontroller to be programmed directly within a circuit without
removing it. By uploading the ArduinoISP sketch through the Arduino IDE and connecting the
appropriate  SPI  pins  between  the  Arduino  Uno  and  the  ATmega8,  users  can  easily  burn
bootloaders or upload programs. This approach is cost-effective and convenient, especially for
prototyping  and  educational  purposes,  as  it  eliminates  the  need  for  dedicated  programming
hardware.

Fig 1: Controlling LED’s with the help of IR sensor’s output

An Infrared (IR) sensor is an electronic device that detects objects or motion by using infrared
radiation, a form of electromagnetic energy beyond the visible spectrum. It typically consists
of an IR emitter and a receiver that work together to detect reflected infrared light from nearby
objects.  When  an  object  comes  within  range,  the  emitted  infrared  light  reflects  back  to  the
receiver, causing a change in the sensor’s output signals.

Code:
run.sh:

avr-objcopy -O ihex -R .eeprom counter.elf counter.hex
avrdude  -c  stk500v1  -p  m8  -P  /dev/ttyACM0  -b  19200  -B  250  -U
flash:w:counter.hex:i

main.c:

#include <avr/io.h>
int main(void)
{
    // Set PB1 and PB2 as output (LEDs)
    DDRB |= (1 << PB1) | (1 << PB2);
    // Set PB0 as input (IR sensor)
    DDRB &= ~(1 << PB0);
    while (1) {
        if (PINB & (1 << PB0)){  // Object detected
            PORTB |= (1 << PB1);   // LED1 ON
            PORTB &= ~(1 << PB2);  // LED2 OFF
        }else{  // No object
            PORTB |= (1 << PB2);   // LED2 ON
            PORTB &= ~(1 << PB1);  // LED1 OFF
        }
    }
}

Discussion:
In this experiment, the ATmega8 microcontroller was successfully programmed using Arduino
Uno as an ISP, demonstrating a practical and low-cost programming method. The IR sensor
was interfaced as a digital input device, providing HIGH or LOW signals depending on object
presence. Based on the sensor output, two LEDs were controlled using conditional logic. The
system  behaved  as  expected:  when  an  object  was  detected,  LED1  turned  ON,  indicating
detection,  while  LED2  turned  OFF.  In  the  absence  of  an  object,  LED2  remained  ON
continuously, serving as a default state indicator. This confirms proper interfacing of input and
output devices and validates the logic implemented in the program.

Conclusion:
The experiment successfully demonstrated the use of Arduino Uno as an ISP to program the
ATmega8 microcontroller. It also showed how an IR sensor can be used for object detection
and how microcontroller pins  can be used to  control output devices like  LEDs. The  results
confirm that embedded systems can be effectively built using simple components and basic
programming techniques.
