**Objectives:**

1. To investigate the feasibility and functionality of implementing a sequential LED blinking pattern using the Atmega32 microcontroller within a Proteus simulation environment.
2. To assess the performance and reliability of the Atmega32 microcontroller in controlling multiple LEDs sequentially, focusing on factors such as timing accuracy and power consumption.
3. To evaluate the effectiveness of Proteus simulation in simulating real-world hardware behavior and validating the designed sequential LED blinking circuit before physical implementation.

**Theory:**

**AVR Study:** The Atmega32 is a popular 8-bit microcontroller from the AVR family manufactured by Atmel (now part of Microchip Technology). It features a rich set of peripherals and is widely used in embedded systems.

**LED Blinking:** In this experiment, the code manipulates the output on PORTC and PORTB to control LEDs connected to each pin. The code iterates through the pins on each port, lighting up a pair of adjacent LEDs at a time. The sequence starts at pin 0 and goes up to pin 7 before reversing the direction.

![](data:image/jpeg;base64...)

*Fig.-1.1: Atmega32 Microcontroller*

**Working Principle:**

1. The **DDRD** is set to **0xFF** to configure all pins on PORTD as outputs.
2. The code uses a continuous loop to iterate through each pin on PORTD.
3. In each iteration, the code lights up a pair of adjacent LEDs by setting the appropriate bit in **PORTD**.
4. A delay of 1 second (**\_delay\_ms(1000)**) is added between each transition for clear visualization.
