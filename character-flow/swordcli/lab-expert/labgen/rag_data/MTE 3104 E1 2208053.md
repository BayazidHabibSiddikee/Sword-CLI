Introduction:
The ATmega32 is an 8-bit AVR microcontroller based on a modified Harvard architecture. It has
separate memories for program and data, which allows faster instruction execution. ATmega32 provides
four 8-bit I/O ports: PORTA, PORTB, PORTC, and PORTD. Each port has: A Data Direction Register
(DDRx) to configure input or output. A PORTx register to write output values. A PINx register to read
inputs. In this experiment, PORTC was used as an output port to drive eight LEDs. Each bit of PORTC
corresponds to one LED [1]. Writing logic 1 turns an LED ON, and writing logic 0 turns it OFF. A
delay was introduced using the _delay_ms() function to make the blinking pattern visible to the human
eye [1].
Fig 1: ATmega32 and it’s pin numbers from perumperindo.co.id
The ATmega32 microcontroller operates at a configurable clock frequency defined by the
macro F_CPU. This frequency is used by delay functions to calculate accurate timing intervals
[1]. The Data Direction Register (DDR) controls whether a port pin acts as an input or output.
Setting a DDR bit to logic ‘1’ configures the corresponding pin as an output [2]. PORT registers
are used to write digital data to output pins. By assigning different binary values to a port,
various LED patterns can be produced. Software delays are generated using the _delay_ms()
function from the <util/delay.h> library, which creates precise delays based on the system clock
[3].

Workings:
•  DDRC is set to 0xFF, which configures all PORTC pins as outputs.
•  First, the value 0x07 is written to PORTC, turning ON PC0, PC1, and PC2.
•  After a delay of 0.1 second, all LEDs are turned OFF.
•  Next, 0x38 is written to PORTC, turning ON PC3, PC4, and PC5.
•  This pattern repeats continuously.
