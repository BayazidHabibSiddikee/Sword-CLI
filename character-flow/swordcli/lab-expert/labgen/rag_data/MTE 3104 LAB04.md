**Theory:**

A 7-segment display counter typically operates by cycling through numerical values from 0 to 9, displaying each digit using a combination of illuminated segments. It's often controlled by a microcontroller or digital circuit, which sends signals to the display to update the digits sequentially. The theory behind its operation involves understanding how to activate the appropriate segments to represent each digit and how to synchronize the counting process with the desired timing. As its name suggests, a 7-segment display consists of seven segments, meaning it consists of seven light emitting diodes or LED’s, which together can be used to form one complete digit on the display. Actually most 7-segment displays contain eight internal LEDs as the eight one is used for a decimal point, usually in one of the bottom corners of the display [1].

**Working Principle:**

The code was executed to control a 7-segment display by configuring certain pins of the microcontroller's I/O ports for input and output operations. The function DisplayDigit was defined to display numerical digits on the 7-segment display.

In the main function, the I/O ports and a variable count were initialized to track the numerical value to be displayed. Initially, a '0' was displayed. Then, an infinite loop was entered where button presses were continuously checked. When a button was pressed, a debounce delay of 250ms was waited to stabilize the input signal.

**Code:**

#include <avr/io.h>

#include <util/delay.h>

static void DisplayDigit(*uint8\_t* num);

int main(void)

{

DDRB = 0x7F;

DDRD &=~ 0x0C;

*uint8\_t* count= 0;

DisplayDigit(count);

while (1)

{

if((PIND & 0x04)==0)

{

*\_delay\_ms*(250);

if(count<9)

count++;

else

continue;

DisplayDigit(count);

}

if((PIND & 0x08)==0)

{

*\_delay\_ms*(250);

if(count>0)

count--;

else

continue;

DisplayDigit(count);

}

}

return 0;

}

static void DisplayDigit(*uint8\_t* num)

{

PORTB &= 0x80;

switch(num)

{

default:

case 0:

PORTB |=0x3F;

break;

case 1:

PORTB |=0x06;

break;

case 2:

PORTB |=0x5B;

break;

case 3:

PORTB |=0x4F;

break;

case 4:

PORTB |=0x66;

break;

case 5:

PORTB |=0x6D;

break;

case 6:

PORTB |=0x7D;

break;

case 7:

PORTB |=0x07;

break;

case 8:

PORTB |=0x7F;

break;

case 9:

PORTB |=0x6F;

break;

}

}
