**LED Blinking:** LED blinking refers to the process of continuously turning an LED (Light Emitting Diode) and off in a repetitive pattern. It is a simple and common demonstration in electronics and microcontroller-based projects. [1]

**Pulldown resistor:** A pull-down resistor is a resistor connected between a signal line and ground in a digital circuit. It ensures that the wire is at a defined low logic level even when there are no active connections with other devices. The pull-down resistor holds the logic signal near to zero volts (0V) when no other active device is connected. It pulls the input voltage down to the ground to prevent an undefined state at the input. [2]

**Working Principle:**

1. The program starts by configuring two pins of PORTC (PC0 and PC1) as input pins using bitwise operations.
2. Another pin of PORTD (PD0) is configured as an output pin to control the LED.
3. Inside the main loop, the program continuously checks if both switches connected to PC0 and PC1 are pressed simultaneously.
4. If both switches are pressed simultaneously, the LED connected to PD0 is turned on by setting the corresponding bit in the PORTD register.
5. If either of the switches is not pressed, the LED is turned off by clearing the corresponding bit in the PORTD register.
6. A small delay is added for debouncing to ensure smooth operation and to avoid rapid toggling of the LED state.
